# أوامر Command-line: اللي تحتاجه واللي ما تحتاجه

مرجع سريع لدراسة CS50 على جهازك: Ubuntu و VS Code و gcc و git.

## الخلاصة

تحتاج فعلياً حوالي 15 أمر. محاضرة Week 1 في CS50x 2026 نفسها تكتفي بسبعة أوامر Linux:

```
cd   cp   ls   mkdir   mv   rm   rmdir
```

والباقي إضافات تخدم شغلك على جهازك: gcc و git.

## الفكرة

الطرفية (Terminal) هي مدير الملفات نفسه، لكن تكتب الأوامر بدل ما تضغط بالماوس.

أي أمر له نفس الشكل:

```
command [options] [arguments]
```

مثال:

```bash
ls -a D8
```

| الجزء | في المثال | معناه |
|:---|:---|---:|
| command | `ls` | اسم الأمر: اعرض المحتويات |
| option أو flag | `-a` | خيار يغيّر سلوك الأمر: اعرض حتى الملفات المخفية |
| argument | `D8` | الشي اللي يشتغل عليه الأمر: مجلد D8 |

## المستوى 1: تحتاجها الآن واحفظها

### التنقل والملفات

| الأمر | وش يسوي | مثال |
|:---|---:|:---|
| `pwd` | يطبع الـ path: عنوان المجلد اللي أنت فيه الآن | `pwd` |
| `ls` | يعرض محتويات المجلد (directory) | `ls -a` |
| `cd` | ينقلك لمجلد ثاني | `cd D9` |
| `mkdir` | ينشئ مجلد جديد | `mkdir D9` |
| `code` | يفتح ملف في VS Code، وينشئه عند الحفظ لو ما كان موجود | `code loop.c` |
| `cp` | ينسخ ملف | `cp calc.c calc2.c` |
| `mv` | ينقل ملف أو يغيّر اسمه | `mv calc2.c add.c` |
| `rm` | يحذف ملف | `rm add.c` |
| `rmdir` | يحذف مجلد فاضي | `rmdir test` |
| `clear` | ينظّف الشاشة | `clear` |

> **تحذير:** الأمر rm يحذف نهائياً، ما فيه سلة محذوفات. لا تنسخ من النت أمر فيه `rm -rf` أو `sudo rm` قبل ما تفهم كل حرف فيه.

### بناء البرنامج وتشغيله

| الأمر | وش يسوي | مثال |
|:---|---:|:---|
| `gcc` | يحوّل كود C لبرنامج يشتغل (compile) | `gcc loop.c -o loop -lcs50` |
| `./` | يشغّل برنامج موجود في المجلد الحالي | `./loop` |

### حفظ الشغل ورفعه (git)

| الأمر | وش يسوي |
|:---|---:|
| `git status` | يبيّن وش تغيّر وما انحفظ |
| `git add .` | يجهّز كل التغييرات للحفظ |
| `git commit -m "D9: loops"` | يحفظ نسخة من شغلك مع وصف قصير |
| `git push` | يرفع النسخ المحفوظة إلى GitHub |
| `git pull` | يسحب آخر نسخة من GitHub، مهم لما تتنقل بين جهازين |

### رموز المسارات

| الرمز | معناه | مثال |
|:---|---:|:---|
| `.` | المجلد الحالي | `git add .` |
| `..` | المجلد الأب: اللي فوق مجلدك الحالي | `cd ..` |
| `~` | مجلد حسابك الرئيسي (home) | `cd ~/Desktop/cs-ce` |

### اختصارات الكيبورد

| الاختصار | وش يسوي |
|:---|---:|
| `Tab` | يكمّل اسم الملف أو المجلد عنك |
| `↑` | يرجّع آخر أمر كتبته |
| `Ctrl+C` | يوقف برنامج علّق، مثل loop ما تنتهي |
| `Ctrl+L` | ينظّف الشاشة، نفس clear |

## المستوى 2: تجيك لاحقاً، لا تحفظها الآن

تعلّم كل أمر منها لما توصله في الدراسة.

| الأمر | وش يسوي |
|:---|---:|
| `make` | يسوي compile بسطر أقصر؛ محاضرات CS50 تكتب `make hello` بدل سطر gcc الطويل، وعلى جهازك يحتاج إعداد إضافي فاستمر على gcc الآن |
| `cat` | يطبع محتوى ملف على الشاشة |
| `touch` | ينشئ ملف فاضي |
| `man` | يعرض دليل استخدام أي أمر، مثل `man ls` |
| `wget` | ينزّل ملف من رابط؛ CS50 يستخدمه لتنزيل كود المحاضرات الجاهز |
| `unzip` | يفك ملف zip |
| `>` | يكتب مخرجات البرنامج في ملف |
| `<` | يعطي البرنامج مدخلاته من ملف |
| `\|` | يوصّل مخرجات أمر بمدخلات أمر ثاني، واسمه pipe |
| `echo $?` | يبيّن هل آخر برنامج نجح أو فشل (exit status) |
| `grep` | يبحث عن نص داخل الملفات |
| `diff` | يقارن ملفين ويعرض الفروقات |
| `gdb` | يمشّي البرنامج سطر سطر عشان تلقى الخطأ (debugger) |
| `valgrind` | يكشف أخطاء الذاكرة، يجي مع pointers |
| `sudo apt install` | يثبّت برامج جديدة على Ubuntu؛ كلمة sudo تعني: نفّذ بصلاحيات المدير |
| `git log` | يعرض تاريخ النسخ المحفوظة |
| `git diff` | يعرض وش تغيّر بالضبط قبل الحفظ |
| `git clone` | ينسخ ريبو من GitHub لجهاز جديد |

هذي أدوات خاصة بـ CS50 وليست من أوامر Linux:

```
check50   style50   design50
```

## المستوى 3: ما تحتاجها في هالمرحلة

| الأوامر | وش هي |
|:---|---:|
| `vim` `nano` | محررات نصوص داخل الطرفية؛ يكفيك VS Code |
| `sed` `awk` `xargs` | معالجة نصوص متقدمة |
| `chmod` `chown` | صلاحيات الملفات |
| `ps` `top` `kill` | إدارة البرامج الشغّالة (processes) |
| `ssh` `scp` | الدخول لجهاز ثاني عن بعد |
| `tar` `curl` `ping` `ip` | ضغط الملفات والشبكات |
| `systemctl` `cron` `df` `du` `mount` | إدارة النظام |
| `find` `ln` `alias` `export` | أدوات إضافية للملفات وإعدادات الطرفية |
| Bash scripting | كتابة سكربتات كاملة بلغة Bash |

مو لأنها غير مهمة، لكنها ما تخدم كتابة C الآن. الصلاحيات والـ processes ترجع لاحقاً مع أنظمة التشغيل.

## مثال: يوم كامل

اكتبها سطر سطر، مو لصق مرة وحدة: لازم تكتب الكود وتحفظه قبل أمر gcc.

```bash
cd ~/Desktop/cs-ce            # ادخل الريبو
mkdir D9                      # مجلد اليوم
cd D9
code loop.c                   # اكتب الكود واحفظه
gcc loop.c -o loop -lcs50     # compile
./loop                        # شغّل البرنامج
cd ..
git add .
git commit -m "D9: loops"
git push
```
